# Plot top-ranked windows

Plot top-ranked windows

## Usage

``` r
plot_top_windows(x, weather_var = NULL, trait = NULL, n = 15L)
```

## Arguments

- x:

  Scan object or correlation results.

- weather_var:

  Optional weather-variable filter.

- trait:

  Optional trait filter.

- n:

  Number of bars.

## Value

A ggplot object.
