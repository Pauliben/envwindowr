# Plot correlation by window start for a selected size

Plot correlation by window start for a selected size

## Usage

``` r
plot_window_profile(x, weather_var, trait, window_days)
```

## Arguments

- x:

  Scan object or results.

- weather_var:

  Weather variable.

- trait:

  Trait.

- window_days:

  Window size.

## Value

A ggplot object.
